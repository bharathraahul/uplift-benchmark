# Decisions log

- 2026-10-12 — Covariate balance (ad vs no-ad): all 12 features have |SMD| < 0.1 (max 0.049), so randomization holds and no reweighting is needed. Chart: `figures/smd_balance.png`.
- 2026-10-12 — Small real imbalance on f3 (SMD −0.049) and f6 (−0.040), likely from pooling several tests with different treatment ratios; noted, not corrected.
- 2026-10-17 — Missing values: 0 of 13,979,592 rows in the raw CSV have a missing value, so `dropna` removes nothing.
- 2026-11-03 — Primary outcome: **visit**; conversion is secondary. Conversion is too rare to model uplift on reliably: the no-ad group has only 813 conversions in the test split (812 in validation), against 15,982 visits. Uplift metrics like Qini rank users by small differences within those few no-ad converters, so conversion estimates would be mostly noise. Visit has about 20× as many events, and its ATE is clearly positive (+1.03 pp, +27%). Conversion results are still reported, as a secondary check.
- 2026-11-03 — Split: 60/20/20 train/validation/test, stratified on treatment × conversion (`random_state=42`), stored as a `split` column in the Parquet rather than three files. Treatment share is 0.850 and conversion rate 0.292% in every split. Visit rate (not stratified) ranges 4.68–4.71%, within sampling noise. Built in `notebooks/01_data_prep.ipynb`.
- 2026-11-03 — Dev sample: 1.5M rows from train, stratified the same way, marked by a boolean `dev` column. Use it for iteration; fit final models on full train.
- 2026-11-03 — Test set is locked: after the split check, no notebook loads test rows until the final evaluation. Load with `pd.read_parquet(path, filters=[('split', '!=', 'test')])`.
- 2026-11-21 — Adjusted vs simple ATE: adjusting for f0..f11 (OLS) lowers the ATE more than expected for a randomized test. Visit goes from 0.0103 to 0.0070 (about 32% lower) and conversion from 0.00115 to 0.00092 (about 20% lower). With every |SMD| < 0.05 the two should be close. Likely cause: Criteo pooled several incrementality tests with different ad/no-ad ratios, so the simple difference in means mixes test-level differences in baseline rates into the effect. Features that differ by test then absorb part of it in the regression, which would also explain the small f3 and f6 imbalances. The test ID is not in the data, so this can't be corrected directly. Both numbers are reported; treat the simple ATE as an upper-leaning estimate, and keep in mind that uplift models may partly learn which test a user came from.
